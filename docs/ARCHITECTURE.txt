│ Endpoint                │ Purpose                                       │
├─────────────────────────┼───────────────────────────────────────────────┤
│ POST /api/generate      │ Generate new questions                        │

DATA FLOW EXAMPLE: Generate Questions
──────────────────────────────────────

1. USER ACTION
   ↓
   User visits: https://username.github.io/grade3-question-generator/
   Clicks "Generate Questions"
   Selects "Math" and "5 questions"
   Clicks "Generate"

2. FRONTEND (JavaScript)
   ↓
   fetch(`${API_BASE_URL}/api/generate`, {
     method: 'POST',
     body: JSON.stringify({ subject: 'math', count: 5 })
   })

3. RAILWAY BACKEND
   ↓
   Flask receives request
   → generator.generate_batch('math', 5)
   → Creates 5 math questions
   → database.add_question() × 5
   → Saves to SQLite
   → Returns JSON: { success: true, questions: [...] }

4. FRONTEND (JavaScript)
   ↓
   Receives response
   → Displays questions in HTML
   → Shows success message

5. USER SEES
   ↓
   5 math questions displayed on screen
   Can now practice with them
